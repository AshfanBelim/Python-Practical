# Python Practicals 🐍

This repository contains my Python practical programs created as part of my programming practice and learning journey. It includes basic Python concepts, mathematical operations, conditional statements, loops, recursion, functions, and a simple game.

### 📚 Programs Included
- Calculator – Perform basic arithmetic operations.
- Count Characters – Count letters, digits, and other characters in a string.
- Even or Odd – Check whether a number is even or odd.
- Factorial of a Number – Calculate the factorial using recursion.
- Fibonacci Series – Generate Fibonacci numbers using recursion.
- Grade Calculator – Calculate average marks and determine grades.
- Greatest Among Three Numbers – Find the largest of three numbers.
- Prime Number Checker – Check whether a number is prime.
- Tic Tac Toe – Play a simple Tic Tac Toe game against the computer.

### 🎯 Purpose
The goal of this repository is to strengthen my Python programming fundamentals through practical examples and hands-on coding.

**Language:** Python  
**Topics:** Basics, Functions, Recursion, Conditional Statements, Loops, and Problem Solving.
